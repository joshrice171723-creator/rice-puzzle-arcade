# Nightfall Scavenger — chunky character study

This is an editable Blender study built from the existing Nightfall Scavenger model and its KayKit Rogue base. It keeps the chunky low-poly direction and adds a relaxed pose, darker hair, a single shoulder plate, and a compact hand-held pistol. The existing scarf, coat panels, and lantern remain.

## Files

- `Nightfall_Scavenger_Chunky.blend` — editable Blender scene with the rig, packed materials, camera, and preview lighting.
- `Nightfall_Scavenger_Chunky.glb` — character-only glTF binary export, including the inherited humanoid skeleton.
- `Nightfall_Scavenger_Chunky_Preview.png` — Blender render of the current pose.
- `source/` — previous Nightfall Scavenger Blender base, original KayKit Rogue model and texture, and CC0 license.

## Provenance

The rigged low-poly base ultimately derives from KayKit's Adventurers Character Pack, Rogue, used under Creative Commons Zero (CC0). KayKit: https://kaylousberg.com/game-assets/characters. The previous Nightfall Scavenger Blender file and original KayKit source files are included in `source/`; `LICENSE.txt` contains the full license text. Nightfall's class artwork informed the navy, ivory, bronze, dark-hair, pistol, and lantern direction; it is not embedded as a character texture.

## Current limits

This is a static Blender review pose. It has no authored idle, walk, turn, or attack animation clips and has not been integrated or tested in the Nightfall Godot gameplay camera. The base face, hands, and body proportions are inherited from the KayKit model; this pass does not claim a custom sculpt or production-ready character.
