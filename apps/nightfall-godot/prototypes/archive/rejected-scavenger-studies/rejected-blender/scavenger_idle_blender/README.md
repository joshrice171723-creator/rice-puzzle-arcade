# Scavenger class idle prototype

Open `scavenger_idle.blend` in Blender 5.2 and play the timeline to preview the six-second idle loop. The rig exposes shape keys for ribcage breathing, a small spine weight shift, hair sway, scarf drift, and coat-hem movement.

This is a 2.5D class-showcase rig built from the existing transparent Scavenger illustration over the existing class-hall art. It preserves the approved painted face, clothes, and proportions; it is not a fully modeled 3D character and is not the gameplay character.

`scavenger_idle_preview.mp4` is a short interpolated review clip. `scavenger_idle_still.png` is the full-resolution scene render. The source Blender build script is `tools/build_scavenger_idle_blender.py`.
