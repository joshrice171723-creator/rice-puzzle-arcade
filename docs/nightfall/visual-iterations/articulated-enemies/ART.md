# Independent enemy parts and assembly

Original built-in imagegen production assets: five 1254 by 1254 transparent atlases in `apps/nightfall-godot/assets/actor-parts/enemies/`: drifter, runner, spitter, bulwark, hexer. Each uses a 4 by 4 layout with complete independent head, torso, hips, paired upper/lower arms/hands and paired thigh/shin/foot parts. Last cell is core or separate weapon. All alpha ranges verified 0..255. No image pixels were modified with Python; region metadata is used for cropping.

Prompts are preserved alongside this document. Manifests under `apps/nightfall-godot/assets/actor-rigs/` contain exact source regions, source joint axes and normalized canonical joints. Source pivots are authored from the actual artwork. Feet use a virtual horizontal axis pointing right, even when the painted toe faces left; source endpoint is pivot.x+0.65, same y. An earlier endpoint of .95 with a .8 pivot caused extreme right-foot scaling and was corrected. Torso breadth and shoulder spacing were tuned from an actual integrated render. Hexer staff grip moved lower on the shaft and the canonical staff length shortened to prevent below-ground shaft overshoot.
