# Hero articulated sprite sources

Created with the built-in image generation tool, 2026-10-19. Original Nightfall hero-cast/equipment-bodies.png supplied as identity/style reference. New transparent full-part artwork is stored in assets/actor-rigs/{scavenger,engineer,warden,arcanist}.png with measured source rectangles and joint anchors in companion JSON files. These are production atlases, not full-pose frame sequences. Source alpha preserved; texture extraction/packing occurs in the engine.

## Shared prompt

Use case: stylized-concept. Production transparent 2D skeletal sprite PART atlas for Nightfall, matching supplied reference's painterly crisp blue/gold fantasy scavenger art. NOT a finished character pose, not a concept mockup. EXACT 4 columns x 2 rows equal grid, eight isolated parts, no labels/gridlines/text, generous transparent separation. Row1 left to right: cape/back coat tails only; torso with collar/scarf belt pouches and shoulder sockets but NO head/arms/legs; detached complete head and hair; single upper arm shoulder to elbow. Row2 left to right: forearm with glove/fist elbow to grip; single trouser thigh hip to knee; single boot shin knee to ankle WITHOUT foot; separate boot foot ankle to sole with toe facing RIGHT. All long limb parts straight vertically downward (proximal rounded joint at TOP, distal rounded joint at BOTTOM), complete concealed joint ends painted so joints can overlap seamlessly in animation; no hollow gaps/crosssections. All 8 occupy their own cell with transparent padding. Head/torso front three-quarter toward right; consistent upper left light, no ground shadow, no weapon. Limbs will mirror for left/right, so single piece per type. Small-screen game readable detail, original same identity palette as reference. Genuine transparent background.
