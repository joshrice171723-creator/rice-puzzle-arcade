# Ember animation asset

Historical asset source: superseded by the continuous geometry/shader implementation in `../CONTINUOUS_COMBAT_VFX.md`. These frames are retained as source history and are no longer used by the Ember renderer.

Generated with the built-in image-generation tool on October 19, 2026. Original output: `exec-304788cc-91e6-4f06-ae54-ab11926192c3.png`; final asset: `apps/nightfall-godot/assets/combat-vfx/ember/sequence.png`.

Four by four transparent sheet. Row 1 has four changing flame flight poses; row 2 is four impact poses; row 3 continues into smoke; row 4 has casting swirls. Production sampling uses equal cells with a 12-source-pixel inset, mipmaps, and a stable projectile core offset. Flight runs at 18 poses per second; impact/smoke runs for 0.72 seconds from the actual hit tick. Reduced Effects preserves contact and pose animation while reducing secondary sparks and light.

The scavenger casting sheet is separate; no character or scenery was extracted from a reference screenshot. Glow is a bounded radial texture drawn as local ground illumination, not a full-screen postprocess.
