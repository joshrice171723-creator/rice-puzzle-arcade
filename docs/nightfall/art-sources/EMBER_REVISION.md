# Ember revision after visual rejection

Historical attempt, subsequently rejected for looking like stitched pictures. The runtime now uses `../CONTINUOUS_COMBAT_VFX.md`; neither Ember sheet drives the attack.

The previous implementation did not meet the approved storyboard. Its fire core was undersized, its soft orange texture lacked the white-hot curls, and its floor lighting was too weak. Functional correctness was not visual acceptance.

This revision uses `assets/combat-vfx/ember/sequence-v2.png`, created with the built-in image tool. Source: `exec-d7a343b7-11e8-4051-9d0c-1fcf1b39060d.png`. The storyboard is a style reference; no scene or source-game imagery was extracted.

The sheet has 16 authored poses, transparent alpha, 4 columns and 4 rows. The runtime keeps an inset gutter, samples with mipmaps, and aligns the flight core independently of the sheet center. Ground illumination is below actors and telegraphs. Health bars render after the main impact. The larger flame does not enlarge collision or damage. Cast, travel, impact and smoke continue to use simulation time, so pause freezes animation.
